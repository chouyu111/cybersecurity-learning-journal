### 📌 今日核心知识点

### 🚀 实战项目演练
*   **防火墙 IP 白名单校验器**：
    *   结合 `input()` 获取用户输入的 IP，遍历白名单列表进行比对。
    *   实现了“命中则放行并 `break` 中断，未命中则拦截”的核心安全逻辑。

### 🐛 踩坑与 Debug 记录
*   **变量名冲突**：起初将用户输入的 IP 和循环遍历的 IP 用了同一个变量名，导致数据被覆盖，后修正为 `blackip` 和 `ip`。
*   **判断逻辑写死**：最初错将正确的 IP 硬编码在 `if` 条件中，忽略了与用户输入变量进行动态比对。
*   **缩进陷阱**：将 `else` 错误地放在了 `for` 循环内部，导致比对不成功就会立刻打印拦截。

### 💡 认知突破与高阶收获
*   **解锁 Python 进阶语法 `for...else`**：在修正 `else` 缩进时，意外探索并验证了 Python 独有的 `for...else` 语法。理解了当循环被 `break` 打断时不执行 `else`，正常遍历完才执行 `else` 的逻辑，这比设标记变量更优雅！
*   **掌握“插旗子法”**：学习了程序员通用的标记变量套路（如 `is_safe = False`），并理解了 `True` / `False` 作为布尔保留字的严格规则（必须首字母大写且不可改名）。
