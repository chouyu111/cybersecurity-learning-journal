*   **工作目录与绝对路径**：学会了用 `os.getcwd()` 打印当前工作目录；在读取文件找不到目标时，学会了使用 `r"C:\..."` 绝对路径来精准定位。
*   **反爬虫与 Headers 伪装**：实战中遇到了 `403拒绝`。彻底搞懂了不能“裸奔”发请求，必须构建 `headers = {"User-Agent": "..."}` 伪装成浏览器，才能骗过服务器的防盗链。
*   **变量作用域与执行顺序**：明白了变量必须在被使用前定义，不能把循环内部的变量（如 `yu`）拿到循环外部去用，否则会报 `NameError`。
*   **文件后缀名与 Content-Type**：了解到服务器返回的图片可能是 `.webp` 格式，不能无脑写死为 `.png`，虽然勉强能看但名不副实。

### 🐛 崩溃实录与 Debug 全记录
1.  **被“资本做局”的缩进**：整个 `for` 循环被无意中缩进到了 `if not os.path.exists()` 里面。导致文件夹已存在时，程序直接跳过了所有下载逻辑，秒速跑完留下一个空文件夹。（被电脑端 AI 一语点醒）
2.  **找不到文件的乌龙**：Python 读不到 `links.txt`，排查后发现不仅是相对路径的问题，还差点被 Windows 隐藏后缀名给坑了。
3.  **NameError 红字轰炸**：把加了 headers 的 `requests.get(yu)` 错误地放在了循环外面，导致电脑执行时 `yu` 还没出生，当场崩溃。
